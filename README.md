# OPNsense Assistant – Downloads

Hier liegen nur die fertigen Versionen des OPNsense Assistant (Hagemann IT-Systeme) zum Herunterladen und für die automatischen Updates.

- Neueste Version: unter **Releases** → `OPNsenseAssistant_<Version>.exe`
- Jede Version ist mit unserem Herstellerschlüssel unterschrieben. Der Assistent installiert Updates nur, wenn die Unterschrift stimmt.
- Für Änderungen an der Firewall ist ein Freischaltcode nötig: lizenz@hit-s.de
